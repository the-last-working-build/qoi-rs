# qoi-rs

A safe Rust port of the reference QOI image encoder and decoder.

Original repository: https://github.com/phoboslab/qoi

Pinned source commit:

    97bacc86a9c4abf5a2d452102dc26546c4c670b9

## Build

    cargo build

## Test

    cargo test

## Project status

The port is currently under development for Port Mortem 2026, Track A:
C to Rust.
